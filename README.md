# 🚗 Cruise Control System Using MATLAB/Simulink

## Overview

This project presents the design and simulation of a **Cruise Control System** using **MATLAB/Simulink**. The objective is to automatically maintain a desired vehicle speed under varying road conditions by adjusting the throttle force through a PID controller.

The system models vehicle longitudinal dynamics and considers real-world disturbances such as aerodynamic drag and road grade (uphill/downhill slopes).

---

## Project Objectives

- Design a closed-loop cruise control system.
- Maintain a desired vehicle speed automatically.
- Analyze vehicle performance under different road conditions.
- Evaluate PID controller effectiveness for speed regulation.
- Study the impact of aerodynamic drag and road grade forces.

---

## System Architecture

The cruise control system consists of:

1. Reference Speed Input (Vref)
2. PID Controller
3. Vehicle Dynamics Model
4. Aerodynamic Drag Force Model
5. Road Grade Force Model
6. Feedback Loop

### Vehicle Dynamics Equation

\[
m\frac{dv}{dt}=F_{throttle}-F_{drag}-F_{grade}
\]

Where:

- \(m\) = Vehicle Mass (1500 kg)
- \(v\) = Vehicle Velocity
- \(F_{throttle}\) = Throttle Force generated by PID Controller
- \(F_{drag}\) = Aerodynamic Drag Force
- \(F_{grade}\) = Road Grade Force

# Simulation Scenarios

## Scenario 1: Flat Road

### Inputs

| Parameter | Value |
|------------|---------|
| Reference Speed | 20 m/s |
| Step Time | 2 sec |
| Road Grade | 0° |
| Grade Input | 0 |

### Results

- Vehicle successfully reaches the desired speed.
- Small overshoot observed.
- Stable tracking achieved.

---

## Scenario 2: Uphill Road (+5°)

### Inputs

| Parameter | Value |
|------------|---------|
| Reference Speed | 15 m/s |
| Step Time | 0 sec |
| Grade Step Time | 5 sec |
| Initial Grade | 0 rad |
| Final Grade | 0.0873 rad (+5°) |

### Results

- Vehicle compensates for additional uphill resistance.
- Speed settles at the desired value.
- Controller increases throttle force to overcome grade force.

---

## Scenario 3: Downhill Road (-5°)

### Inputs

| Parameter | Value |
|------------|---------|
| Reference Speed | 15 m/s |
| Step Time | 0 sec |
| Grade Step Time | 5 sec |
| Initial Grade | 0 rad |
| Final Grade | -0.0873 rad (-5°) |

### Results

- Vehicle experiences temporary overshoot due to downhill assistance.
- PID controller reduces throttle force.
- Speed gradually returns toward the desired value.

---

## Road Grade Force

The road grade force is calculated as:

\[
F_{grade}=mg\sin(\theta)
\]

### Uphill

\[
F_{grade}=1500\times9.8\times\sin(5^\circ)
\]

\[
F_{grade}\approx1281N
\]

### Downhill

\[
F_{grade}=1500\times9.8\times\sin(-5^\circ)
\]

\[
F_{grade}\approx-1281N
\]

## Key Learnings

- PID control effectively regulates vehicle speed.
- Road grade disturbances significantly affect vehicle dynamics.
- Uphill conditions require higher throttle force.
- Downhill conditions can cause overshoot if not compensated properly.
- Feedback control improves speed stability and disturbance rejection.
